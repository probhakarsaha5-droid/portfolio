# Probhakar Saha — Portfolio

Personal portfolio website for **Probhakar Saha**, Computer Science student and aspiring Full-Stack Developer.

Built with **React 18**, **Vite**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**.

## Features

- Modern, minimal, light-themed design with subtle animations
- Typing animation in the hero section
- About, Experience, Skills, Services and Projects sections
- Working contact form powered by EmailJS
- Fully responsive layout

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:8080 to view the site.

## Build

```bash
npm run build
```
